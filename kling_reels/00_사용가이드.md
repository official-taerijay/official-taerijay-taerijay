## 오탈자 방지 3원칙

1. **프롬프트의 텍스트는 항상 따옴표로 감싸고, 뒤에 "spelled exactly as written, no typos, no extra characters"를 붙였습니다.** Kling에 그대로 복사해서 사용하세요 — 임의로 문구를 줄이거나 바꾸지 마세요.
2. **한 화면에 텍스트 1개만 노출되도록 설계했습니다.** 여러 문장이 동시에 겹치면 오탈자·잘림 확률이 급격히 올라갑니다.
3. **생성 후 반드시 확대(zoom)해서 한 글자씩 대조하세요.** 오탈자가 나오면:
   - 같은 프롬프트로 재생성 (Kling은 매 생성마다 다른 결과를 냄)
   - 그래도 반복되면 "clean minimal typography, no decorative font distortion"을 추가하거나, 문제되는 단어의 자모/스펠링을 프롬프트에서 하이픈으로 분리 표기 (예: "GS25" → "G-S-2-5"로 명시했다가 나중에 편집으로 정리)

## 여유 있는 시작/마무리 설계

Gemini에서 겪었던 "너무 급하게 시작하고 너무 빠르게 마무리"되는 문제를 막기 위해 모든 프롬프트에 아래 장치를 넣었습니다.

- **오프닝**: 첫 1.5~2초는 텍스트 없이 배경/장면만 유지 (급발진 방지)
- **텍스트 홀드타임**: 모든 텍스트는 최소 1.5~2.5초간 화면에 고정 노출 (스쳐 지나가지 않도록)
- **마무리**: 마지막 문구는 최소 2초 이상 유지된 뒤, 페이드아웃은 영상의 마지막 0.5초에만 발생하도록 명시 (문구가 잘리기 전에 컷되는 것 방지)
- 모든 프롬프트에 "generous pacing", "never cut off", "deliberately unhurried" 같은 표현을 반복적으로 넣어 Kling이 템포를 서두르지 않도록 유도했습니다.

## 영상 길이

서비스별로 자유롭게, 최대 20초 이내로 설정했습니다. 실제로는 18~19초로 여유를 두고 만들어서, Kling 실제 생성 길이가 딱 맞지 않을 경우를 대비했습니다 (필요시 21~22초로 늘려 생성 후 편집에서 다듬는 것을 권장).

## 진행 순서 제안

1. `00_taerijay_main.md`의 "전체 프롬프트"를 Kling에 입력해 생성
2. 결과를 확대해서 "TAERIJAY", "TAERIJAY.COM" 철자 확인
3. 문제 없으면 6개 채널로 순서대로 진행 (entertainment → protocol → mini → red → green → mart+convenience)
4. 브랜드명(GS25, CU, 세븐일레븐 등)이 들어가는 06번은 특히 꼼꼼히 확인
5. 전체 생성 후 오탈자 없는 영상들을 편집기(CapCut 등)에서 순서대로 이어붙이기

## 실사이트 기준 정정 사항 (이전 Gemini 프롬프트 대비)

이전 Gemini용 프롬프트는 채널 카테고리를 추정으로 작성했었는데, 실제 taerijay.com을 확인한 결과 다음과 같은 차이가 있었습니다.

- **protocol**: 실제 12개 카테고리(무료5+유료7) — 이전엔 대략적 서술이었음
- **mini**: 실제 13개 카테고리(무료3+유료10), "3시간/반나절/1일/2일/3일" 외에 예약결제, 응급통역, 야경/사진맛집/실내코스, K-드라마 촬영지 등이 별도로 존재
- **red/green**: 실제로는 카테고리 구성이 완전히 동일(마스크팩~품절대란템 12개), 전체 유료(무료 0개) — 이전엔 무료 뉘앙스가 섞여있었음
- **mart+convenience**: 실제 7개 브랜드는 이마트·노브랜드·트레이더스·이마트24·CU·GS25·세븐일레븐이며 브랜드별 무료5+유료25=30개씩

이번 Kling 프롬프트는 모두 위 실사이트 데이터를 반영했습니다.
